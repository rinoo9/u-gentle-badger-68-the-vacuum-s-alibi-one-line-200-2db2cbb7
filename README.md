# The Vacuum's Alibi — "I do not chase furniture."

A one-line entry for the make.fun bounty "The Vacuum's Alibi: One Line, 200 Characters". The program `main.py` writes the robot vacuum's deadpan excuse — 135 characters, one line, punch at the end — to `/output/entry.txt`.

> Missed the crumb under the table. My sensors logged it as furniture: it had legs, it moved, and it outran me. I do not chase furniture.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
